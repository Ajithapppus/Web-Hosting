1. Zip upload cheythu hostname anusarichu serve cheyyuka Aadyam ithu cheyyuka

HTML/CSS/JS static sites (ninte client sites polullava) host cheyyaan ithu mathi.

  • Dashboard-il "Upload site" button. Zip server-il sites/<slug>/ folder-il extract cheyyanam.
  • Packages: npm i multer adm-zip
  • db.ts-il getProjectByHost(host) add cheyyanam. Subdomain-um customDomain-um check cheyyanam.

Serving middleware (server.ts-il, /api-nu munpe):

import fs from 'fs';
import path from 'path';

const SITES_DIR = path.resolve('sites');

app.use((req, res, next) => {
  const host = req.hostname.toLowerCase();
  const project = db.getProjectByHost(host);
  if (!project) return next();            // Storvia dashboard thanne

  const root = path.join(SITES_DIR, project.slug);
  if (!fs.existsSync(root)) return res.status(404).send('Site not uploaded yet');
  express.static(root)(req, res, () =>
    res.sendFile(path.join(root, 'index.html'))
  );
});
Zip-slip sradhikkuka: zip extract cheyyumbol ellaa file path-um sites/<slug>/-nu ullil aano ennu check cheyyanam (../ ulla path reject cheyyanam). Illenkil upload cheyyunnavar server-ile files overwrite cheyyum.

2. Real DNS check, custom domain

Ippo /projects/:id/custom-domain ethu domain koduthaalum "verified" aakum. Athu maattanam.

import dns from 'dns/promises';

async function isPointingToUs(domain: string, serverIp: string) {
  const a = await dns.resolve4(domain).catch(() => []);
  const cname = await dns.resolveCname(domain).catch(() => []);
  return a.includes(serverIp) || cname.some(c => c.endsWith('yourdomain.com'));
}
  • Verify aayillenkil customDomainVerified: false aayi vekkuka. User-nu "A record ittathinu shesham Verify press cheyyuka" ennu kaanikkuka.
  • Platform domain-nu wildcard DNS: *.yourdomain.com server IP-lekku point cheyyanam.

3. Real server-il run cheyyuka, SSL

  • VPS edukkuka (Hetzner, DigitalOcean, AWS Lightsail). Laptop-il ninnu public hosting pattilla.
  • Front-il Caddy vekkuka. Custom domain-nu Let's Encrypt SSL automatic aayi edukkum (on-demand TLS).
  • Node app pm2 allenkil Docker vazhi run cheyyuka. NODE_ENV=production, npm run build.
  • data/*.json maari SQLite allenkil PostgreSQL aakkuka. JSON file concurrent writes-il corrupt aakaam.

4. Security fixes (production-nu munpe nirbandham)

  • POST /auth/demo-switch password illaathe admin login tharum. Remove cheyyuka, allenkil development-il maathram enable cheyyuka.
  • /auth/forgot-password reset token response-il thanne return cheyyunnu. Ithu email vazhi maathram ayakkanam.
  • Upload size limit, file type check, per-user storage limit ennivayum venam.
  • Session tokens, password hashing ennivayum production-nu yogyamaano ennu db.ts-il review cheyyuka.

5. GitHub build, Node apps Pinne

Repo clone cheythu npm run build run cheyyaan isolated sandbox venam. Ithu risky aanu, athukondu aadyam venda.

  • Ororo build-um Docker container-il, CPU/memory/time limit vechu run cheyyanam.
  • Output folder (dist, .next) sites/<slug>/-lekku maattanam. Pinne step 1 pole serve cheyyam.
  • Node/Next.js server apps-nu ororo app-num port, reverse proxy venam.

Chuttum kidakkunna vazhi: already live site proxy cheyyuka

Client site vere ekkidathenkilum host cheythittundenkil, upload illaathe client.storvia.app aa URL-lekku forward cheyyaam:

// npm i http-proxy-middleware
import { createProxyMiddleware } from 'http-proxy-middleware';

app.use((req, res, next) => {
  const p = db.getProjectByHost(req.hostname);
  if (!p?.targetUrl) return next();
  createProxyMiddleware({ target: p.targetUrl, changeOrigin: true })(req, res, next);
});

Project model-il targetUrl field add cheyyanam (types.ts, deploy form).
